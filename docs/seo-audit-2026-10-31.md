# Technical SEO and content audit, 31 October 2026

Scope: the live site at https://2bhkinteriors.in, the React app in `frontend/`, the Hostinger deploy, `robots.txt`, sitemaps, and the contact backend. Live checks were run against production before any change.

## Fixed in this change

### Crawling and indexing
| Issue found | Evidence | Fix |
|---|---|---|
| Inner pages had no URLs of their own. About, Services and Portfolio switched inside one page with `useState`, yet the sitemap listed `/about`, `/services` and `/portfolio`. | Live `/about` returned the home page shell. | Real routes `/about/`, `/services/` and `/portfolio/` using the History API. The back and forward buttons work. Nav, footer and breadcrumb links are now `<a href>` links that crawlers can follow, not buttons. |
| Client-side rendering only: the HTML had an empty `<div id="root">`. | `index.html` | Every route is prerendered to static HTML at build time (`scripts/prerender.mjs`) and then hydrated. Crawlers get the full text, headings and links without running JavaScript. |
| Every URL had the same title, description and canonical (the home page's). | `index.html` | Each page has its own title (56–58 characters), description (148–154), canonical, Open Graph tags and Twitter tags, defined in `src/site.js`. They are written into the HTML and also updated during in-app navigation. |
| Soft 404s: any made-up URL returned 200 with the home page. | Live `/nonexistent-page-xyz` returned 200. | Removed the SPA catch-all rewrite. Unknown URLs now return a real 404 with a `noindex` page (`404.html`) that links back to the main pages. |
| The `www.` host served a duplicate copy of the site. | Live `https://www.2bhkinteriors.in/` returned 200. | 301 from `www.` to the bare domain. HTTP to HTTPS was already handled by Hostinger's CDN. |
| URLs had more than one form. | — | 301 redirects from `/index.html` to `/` and from `/about` to `/about/`, matching the canonical tags. |
| `RobotsMeta` rewrote the sitemap link to `2bhkinteriors.com` at runtime. That domain returns 502. | `src/robot.tsx` | Removed the dead `robot.tsx` and `sitemap.ts` files and the root `robot.tsx`. |
| The sitemap was hand-written, listed URLs that didn't exist, and included a 35 MB PDF and ignored `priority`/`changefreq` values. | `public/sitemap.xml` | `sitemap.xml` and `robots.txt` are generated from the route list on each build. The sitemap contains real URLs with trailing slashes and image entries. |
| A stale, committed root `dist/` folder duplicated the site but was never deployed. | The deploy uses `frontend/dist`. | Removed the folder from the repo; it was already in `.gitignore`. |

### On-page
| Issue | Fix |
|---|---|
| The home H1 ("Timeless interiors, designed around you") had no topic or location. | The H1 is now the eyebrow line "Residential Interior Designer in Mumbai". The tagline looks exactly the same as before but is now a paragraph. |
| Services H1 was "Our Services"; Portfolio H1 was "2BHK Interiors Master Portfolio Presentation". | Changed to "Interior Design Services in Mumbai" and "Residential Interior Design Portfolio". |
| FAQ answers were only in the page when expanded, so crawlers saw one answer per page. | All answers are now in the HTML (hidden when collapsed), with proper accordion ARIA. FAQ text lives in `src/content/faqs.js` and also feeds the FAQPage schema. |
| No structured data. | JSON-LD: Organization and WebSite on the home page; BreadcrumbList on inner pages; WebPage and FAQPage on every page. The Organization has only the details we actually know (city and region); phone, email and social profiles are added automatically once they're filled in. |
| The meta keywords tag (ignored by Google); `lang="en"`. | Removed the keywords tag; set `lang="en-IN"` and `og:locale` to `en_IN`. |
| Decorative images had alt text like "Testimonial Atmosphere" and "CTA Background Vignette". | Decorative images now use `alt=""`. |

### Performance
| Issue | Fix |
|---|---|
| Images were 15.4 MB in total (each 1024 px JPEG was about 800 KB). | Recompressed to 3.2 MB at quality 78 with progressive encoding, keeping the same dimensions. Deleted 5 images nothing used. |
| The portfolio PDF was 34.9 MB, and the Portfolio page loaded it in an iframe as soon as you opened the page. | PDF re-encoded to 2.6 MB with the same 17 pages; rendered pages are visually identical. It now loads only when the visitor clicks "Load presentation". Size labels updated. |
| No lazy loading. | Images below the fold use `loading="lazy"`; the hero images get `fetchpriority="high"`. |
| An unused Google Font family (Cinzel) and unused Cormorant weights were downloaded. | Trimmed the font request. |
| `framer-motion` was installed but never used. | Removed it. |
| Cache headers: hashed JS/CSS cached for only 1 month, HTML for 1 hour. | Hashed bundles cached for 1 year (immutable), HTML for 5 minutes, images for 30 days. Added gzip for XML and SVG and basic security headers. |

### Content honesty and user experience
| Issue | Fix |
|---|---|
| The testimonials were template placeholders ("Sarah", "Marcus Vance", "Elena Rostova, Boutique Hotel Owner"). A hotel client contradicts the "exclusively residential" claim. Fake reviews break Google's policies and Indian consumer-protection rules on reviews. | Section hidden. Add real, permitted quotes to `TESTIMONIALS` in `src/site.js` and it reappears. |
| Placeholder phone "+91 98200 12345" and `hello@2bhkinteriors.com`, an inbox on a domain that doesn't resolve, appeared in the footer and CTA. Fake contact details hurt local SEO and lose leads. | Hidden. Fill in `BUSINESS.phone` and `BUSINESS.email` in `src/site.js` and they show up as clickable links. |
| Social links pointed to the instagram.com, pinterest.com, linkedin.com and houzz.com home pages, and "Follow @2bhkinteriors" pointed to instagram.com. | Hidden until real profile URLs are set in `BUSINESS.social`. |
| The footer newsletter form didn't send anything but told people "We've reserved your priority consultation access". | It now sends the sign-up to the same inbox as consultation requests and shows an honest confirmation. |
| The consultation popup opened 1.5 s after arrival on every first visit. Google treats that as an intrusive interstitial on mobile. | It now opens once the visitor scrolls 40% of the page or after 30 s. `?popup=true` still forces it for testing. |
| Form placeholders read "Acme Corp / South Delhi", "Eleanor Vance" and "Company"; inputs weren't linked to their labels. | Mumbai-relevant placeholders, labels linked to inputs, autocomplete hints, dialog ARIA, and a hidden honeypot field against spam bots. |

### Security (contact backend)
| Issue | Fix |
|---|---|
| **A Resend API key was hard-coded, base64-encoded, in `backend/worker.js`** and is in the git history. | Removed it. The worker reads only the `RESEND_API_KEY` secret and fails cleanly if it isn't set. **The key must be revoked and replaced; see below.** |
| Form fields were inserted unescaped into the notification email's HTML, so anyone could inject HTML or links into your inbox. | All fields are escaped and length-limited in the worker and in `backend/server.js`. |
| Bot spam. | Honeypot check: bot submissions get a 200 response but no email is sent. |
| The Express controller defaulted the budget to "$50,000 - $100,000". | Now shows "Not provided". |

## Needs the site owner

1. **Revoke the leaked Resend key now.** It is public in the repo history. In Resend, delete that key and create a new one. Then set it on the worker and redeploy it (the Hostinger workflow doesn't deploy the worker):
   - `cd backend && npx wrangler secret put RESEND_API_KEY`
   - `npx wrangler deploy`

   If the secret is not set, the consultation form will return an error once this worker code is deployed.
2. **Real business details** in `frontend/src/site.js`: phone, an email on the live domain, and social profile URLs. A Google Business Profile with the same name, phone and area matters most for local search in Mumbai.
3. **Real testimonials**, with the clients' permission, in `TESTIMONIALS`.
4. **Claims only you can confirm:**
   - "150+ homes designed", "3 years" and "5+ localities" (stats strip and About page)
   - "a tailored quote in 30 minutes — guaranteed" and "get in touch within 30 minutes — guaranteed" (consultation form)
   - whether the hero and stock images are your own projects; some components describe them as AI images

   These were left unchanged.
5. **After deploying, check in the browser or with `curl -I`:**
   - `https://www.2bhkinteriors.in/` → 301 to the bare domain
   - `/about` → 301 to `/about/`
   - `/about/` → 200, and View Source shows the page text
   - `/made-up` → 404

   Then submit `https://2bhkinteriors.in/sitemap.xml` in Google Search Console and request indexing for the four pages.
6. **City guides** (`/interior-design/`): no page is published yet. See `frontend/reports/2026-10-30.md` for the decisions needed before publishing. Once a guide is published, add a link to the `/interior-design/` hub in the main site's nav or footer.
